# AI Infra 学习路线图

> 从零到能面试 AI Infra 岗位的 **60 周计划**（约 14 个月）
> 面向：在读研究生 / 每天可投入 3-4 小时 / 编程刚起步、主要会 Python

---

## 这个仓库是什么

一份**可执行、可打勾、可追踪**的 AI Infra 自学计划。不是资源收藏夹，而是排好序的任务清单——每周该干什么、干到什么程度算过关、产出什么，都写清楚了。

**核心理念：这条路不是"学一堆知识"，而是"造几个东西"。**
所有阶段的检验标准都是「我能不能亲手实现/优化它」，而不是「我看懂了」。

---

## 起点假设

| 项目 | 假设 |
|---|---|
| 时间投入 | 每天 3-4 小时，每周 20-25 小时 |
| 编程基础 | 刚起步，主要会 Python，C/C++ 基本空白 |
| 系统基础 | 没系统学过操作系统、计算机组成原理 |
| 硬件条件 | 一台普通笔记本（能用云 GPU 补足） |
| 目标方向 | AI Infra（推理引擎 / 分布式训练） |

> 如果你的基础或时间不同，直接按比例缩放大阶段周数即可，阶段顺序不要变。

---

## 总览：8 个阶段

| 阶段 | 周次 | 时长 | 核心产出 |
|---|---|---|---|
| **0. 准备与认知** | W1 | 1 周 | 跑通一次大模型推理，知道 Infra 是什么 |
| **1a. 编程预热** | W2–W7 | 6 周 | Linux + Git + Python 强化 + C 语言入门 |
| **1b. 系统基础** ⚠️ | W8–W22 | 15 周 | CSAPP + OS + 算法 + C++，手写线程池/内存池 |
| **2. GPU 与并行** | W23–W30 | 8 周 | 手写 CUDA 算子，性能逼近 cuBLAS |
| **3. 模型与框架** | W31–W36 | 6 周 | 从零实现 mini GPT 并训练 |
| **4. 分布式训练** | W37–W46 | 10 周 | 手写 Ring AllReduce + MFU 优化报告 |
| **5. 推理系统** 🔥 | W47–W55 | 9 周 | **从零写一个 mini 推理引擎** |
| **6. 进阶与求职** | W56–W60 | 5 周 | 简历、项目包装、面试冲刺 |

## 怎么用这个仓库

**每周日晚上（20 分钟）**
1. 打开 [SCHEDULE.md](SCHEDULE.md)，看下周的任务
2. 在 [PROGRESS.md](PROGRESS.md) 里确认上周的勾打完了没
3. 如果落后超过 2 周，调整计划而不是硬追

**每天晚上（3-4 小时）**
- 1 小时：看教材 / 论文 / 视频
- 2-3 小时：**动手写代码**（这个比例不能反）

**每周结束**
- [ ] 有没有可以提交的代码？（没有 = 这一周白过了）
- [ ] 有没有记录笔记或写博客？
- [ ] `git commit` 了吗？

**每完成一个项目**
- 写一篇博客 / README，讲清「做了什么、遇到什么问题、怎么解决的、数据是多少」
- push 到这个仓库，并在 [PROJECTS.md](PROJECTS.md) 里标记完成

## 三条铁律

1. **不许只看不写。** Infra 是手艺活，看十篇文章不如自己写一个 kernel。
2. **不许跳阶段。** 尤其别跳过 1b，那是 90% 的人失败的地方。看不懂框架源码不是因为你笨，是因为系统基础没打。
3. **每阶段必须有可提交的产出。** 面试官不看"我学过什么"，只看"你做了什么、数据是多少"。

---

## 五个最常见的坑

1. ❌ 一上来就读 vLLM 源码 → 会在 C++/CUDA/系统的墙前撞死
2. ❌ 追求"学完再动手" → 永远学不完，用项目倒逼学习
3. ❌ 忽视系统基础 → 这是 Infra 和"调包侠"的分界线，也是天花板所在
4. ❌ 为了学习先买贵显卡 → 前期用云，确认能坚持再买
5. ❌ 只学不输出 → 博客、开源、PR 是求职时唯一能证明你的东西

---

## 关键提醒

- **W22 结束就可以开始投实习了**，不用等学完。边做边补是最快的路径。
- **前 5 个月很苦且看不到回报**（系统基础期），第 6 个月开始你会突然发现——框架源码都能看懂了。这就是 Infra 的学习曲线：前期慢，后期陡峭上升。
- **硬件不用一步到位**：W1–W22 用现有电脑，W23 开始用 Colab / 云 GPU，等确定要坚持了再考虑配一台 16G/24G 显存的台式机。
- **公开这个仓库**：持续提交记录本身就是你最好的简历。
